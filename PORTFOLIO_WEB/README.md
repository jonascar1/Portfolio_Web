# Portfólio Web

Projeto desenvolvido com Django e Django REST Framework para apresentação de informações pessoais, projetos e certificados, além da implementação de uma API REST para gerenciamento de tarefas com autenticação JWT.

## Funcionalidades

- Exibição de informações pessoais
- Exibição de projetos desenvolvidos
- Exibição de certificados
- Gerenciamento de tarefas via API REST
- Autenticação utilizando JSON Web Token (JWT)
- Controle de acesso baseado em usuário autenticado

## Tecnologias Utilizadas

- Python
- Django
- Django REST Framework
- Simple JWT
- SQLite
- HTML
- CSS

## Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de praticar o desenvolvimento web utilizando Django, incluindo criação de páginas dinâmicas, modelagem de dados, desenvolvimento de APIs REST e autenticação baseada em tokens.
